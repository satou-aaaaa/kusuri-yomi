# 薬の袋よみ

薬の袋に書いてある「食前」「食後」「食間」「寝る前」「頓服」「1日3回」などを読んで、いつ・いくつ飲むかを選ぶ1日5問のゲーム。高齢の人も遊べるように、大きな文字・押すだけ・時間制限なしで作っています。

- 遊ぶ: https://satou-aaaaa.github.io/kusuri-yomi/
- 今日の5問（やさしい2・ふつう2・むずかしい1）はだれでも同じで1日1回。上級（むずかしい3問・ヒントなし）・練習・とことんは好きなだけ遊べます。
- まちがえても選び直せます。正解すると、言葉の意味と出どころが出ます。ヒントは「見るところ」→「選び肢を2つにしぼる」の2段。
- 取りこぼした日は、過去7日までカレンダーからあとから遊べます。

## 本当の薬について

ゲームの中の薬・時刻・数はたとえです。本当の飲み方は、医師・薬剤師の指示と、薬の説明書に従ってください。分からないとき・飲み忘れたときは、医師や薬剤師に相談してください。このゲームは医療の相談の代わりではありません。
